# Koready

공공데이터 기반 관광지·이동 데이터로 동선을 설계하고, 국적별 실제 카드소비 통계로 경비를 예측해주는 **방한 외국인 전용 여행 계획 서비스**

## 기획 배경

2026년 1분기 방한 외래관광객 476만 명(역대 최대), 연간 전망 2,200만 명.
시장은 커지지만 외국인 대상 한국 여행 계획·경비 예측 서비스는 앱스토어 여행 카테고리 top 100에 존재하지 않는다.

## 핵심 기능

| 기능 | 설명 |
|---|---|
| **조건 기반 장소 추천** | 국적·도시·날짜·인원·여행 스타일 → TourAPI 관광지 DB 필터링 |
| **동선 자동 설계** | 좌표 기반 이동시간 + 영업시간 제약 반영, 방문 순서 자동 배치 |
| **국적별 경비 예측** | 확정 일정 × 국적별 신용카드 관광소비 통계 → 업종별 예상 경비 |

## 차별점

|  | 기존 앱 | Koready |
|---|---|---|
| 장소 추천 | AI 나열 | 공공 관광지 DB 조건 필터링 |
| 동선 | AI 순서 배치 | 실제 이동 데이터 + 이동시간 계산 |
| 경비 | 근거 없는 숫자 | 국적별 실제 카드소비 통계 |
| 근거 | 없음 | 출처·기준·한계 명시 |

## 기술 스택

- **Frontend**: React Native, NativeWind v4
- **Backend**: Spring
- **Database**: PostgreSQL, Redis (TourAPI 응답 캐싱)
- **Map**: 카카오맵 / 네이버 지도 API
- **Design**: Figma
- **외부 API**: [TourAPI](https://api.visitkorea.or.kr/#/), [공공데이터포털](https://www.data.go.kr/data/15101972/openapi.do)

## 사용자 흐름

**여행 전**:
1. 서비스 접속
2. 조건 입력 (국적·도시·날짜·인원·스타일)
3. 장소 추천
4. 동선 자동 설계
5. 경비 예측 확인

**여행 중**:
1. 오늘의 일정·동선 확인
2. 다음 장소까지 경로 안내 (도보·대중교통·택시)
3. 현장에서 메뉴판·간판·안내문 번역
4. 일정 변경 시 동선·경비 실시간 재계산

## MVP 범위

**구현 대상**
- 조건 기반 장소 추천 (TourAPI 연동)
- 동선 자동 설계 (이동시간 계산)
- 국적별 경비 예측 (카드소비 통계 적용)

**제외**
- 서울 외 지역 확장
- 실시간 결제·예약 연동
